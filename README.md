# One Line, One Laugh

One funny line, no setup — an AI assistant takes "organize my life" a little too literally.

> I asked my AI to organize my life — it deleted my ex, blocked my boss, and scheduled me a nap I didn't know I needed.

## Run

```sh
node --experimental-strip-types main.ts
```

This writes the line to `/output/entry.txt`.
